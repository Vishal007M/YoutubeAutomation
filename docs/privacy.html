🎬 Bloomtoon

AI-powered YouTube Kids Shorts automation tool.

Privacy Policy

Last updated: September 2026

What this app does

Bloomtoon is a personal automation tool that creates and uploads educational short videos to YouTube using the YouTube Data API v3. It uses Google Gemini AI to generate scripts and metadata, edge-TTS for voice narration, and the Pexels API for background images.

Data We Collect

This application does not collect, store, or share any personal data from users. The app runs entirely on the developer's own computer.

YouTube API Usage

This app uses the YouTube Data API v3 solely to upload videos to the developer's own YouTube channel. No user data from YouTube is collected, stored, or shared with any third parties. For more information, see YouTube's Terms of Service and Google's Privacy Policy.

OAuth Tokens

The app uses Google OAuth 2.0 to authenticate with YouTube. The authentication token is stored locally on the developer's computer only and is never transmitted to any external server.

Third-Party Services

  • Google Gemini AI — script and metadata generation
  • Pexels — background images
  • Microsoft Edge TTS — voice narration

No personal data is shared with these services beyond what is necessary for the app to function.

Revoking Access

You can revoke this app's access to your Google account at any time by visiting Google Account Permissions.

Contact

For questions about this privacy policy, contact the developer directly via the GitHub repository.
